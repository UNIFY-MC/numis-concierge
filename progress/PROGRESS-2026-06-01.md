- "Portugal Bebé" e "(carteira)" partilham catalog_coin; diferença vai em `collection.formato_posse`
- Campos sem dados no HTML (metal completo, grau, preços, fotos, km_ref) ficam NULL — preencher depois via Numista API (não inventar)
